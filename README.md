# RetailOps AI
## Business problem
Multi-outlet retailers often have sales and stock data spread across files and systems. That makes it difficult to see what is selling at each outlet, spot data errors, and make inventory decisions based on trustworthy numbers. RetailOps AI will eventually use that data to support demand forecasting and inventory decisions.
## Phase 1 goal
Design tables for products, outlets, and sales.
Validate CSV data and load it into PostgreSQL.
Write SQL queries for daily sales, revenue, and outlet comparisons.
Handle missing, invalid, and duplicate records.
Test that loading the same file twice does not double-count sales.
